
### **Контрольні запитання**

1. **Маршрутизатор та комутатор:** Комутатор працює в межах однієї мережі за MAC-адресами, а маршрутизатор з'єднує різні мережі через IP-адреси.


2. **Найдовший збіг префікса:** Принцип, за яким обирається маршрут із найдовшою маскою (/X), бо він найбільш точний.


3. **RIP і OSPF:** RIP рахує лише кількість проміжних вузлів і працює повільно. OSPF враховує пропускну здатність і швидко оновлює дані.


4. **Призначення BGP:** Протокол для глобального інтернету, що пов'язує мережі окремих провайдерів і країн.


5. **Варіанти NAT:**
* **Статичний:** Прив'язує один внутрішній IP до одного зовнішнього.


* **Динамічний:** Видає тимчасовий зовнішній IP із наявного пулу.


* **PAT:** Задіює один зовнішній IP для багатьох внутрішніх, розрізняючи їх за номерами портів.




6. **Потреба у прокиданні портів:** Необхідне для того, щоб роутер знав, на який саме ПК всередині мережі спрямувати вхідне з'єднання з інтернету.


7. **Реакція на обрив зв'язку:** Статичний маршрут залишається незмінним і втрачає пакети. Динамічний автоматично перебудовує шлях.


8. **Вибір шляху RIP та OSPF:** RIP вибрав шлях із меншою кількістю роутерів, а OSPF — із більшою швидкістю. Варіант OSPF кращий, бо забезпечує швидшу передачу.


9. **Поля `show ip nat translations`:**
* **Inside local:** Власна локальна адреса ПК.


* **Inside global:** Зовнішня адреса, під якою ПК видно в мережі.


* **Outside local/global:** Адреса сервера в інтернеті.



### **Домашнє завдання**

1. **Вибір маршруту для 10.20.5.10:**
* **Результат:** `10.20.5.0/24`.


* **Пояснення:** Маска `/24` є найдовшою серед усіх варіантів, тому цей запис є найточнішим.




2. **Перегляд таблиці маршрутизації:**
* **Команда:** `route print` (Windows) або `ip route` (Linux).


* **Маршрут за замовчуванням:** `0.0.0.0/0`.


* **Шлюз:** `192.168.1.1` (IP-адреса вашого домашнього роутера).
