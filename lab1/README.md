# 1. Переведення цілого числа N = 91

## У двійкову систему 
 91 \ 2 = 45 (остача 1)
 45 \ 2 = 22 (остача 1)
 22 \ 2 = 11 (остача 0)
 11 \ 2 = 5 (остача 1)
 5 \ 2 = 2 (остача 1)
 2 \ 2 = 1 (остача 0)
 1 \ 2 = 0 (остача 1)
Результат : 1101101


# У вісімкову систему 
91 \ 8 = 11 (остача 3)
11 \ 8 = 1 (остача 3)
1 \ 8 = 0 (остача 1)
Результат: 331


# У шістнадцяткову систему
91 \ 16 = 5 (остача 11 - позначається як B)
5 \ 16 = 0 (остача 5)
