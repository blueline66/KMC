

## Контрольні запитання

1. **CSMA/CA vs CSMA/CD:**
   * **CSMA/CD (дротові):** виявляє колізію під час передачі й зупиняє її.
   * **CSMA/CA (бездротові):** запобігає колізії — прослуховує канал і чекає випадкову паузу.
2. **Проблема прихованого вузла:** Два пристрої не бачать один одного через перешкоду, але обидва бачать точку доступу. Вони відправляють дані одночасно й створюють колізію на приймачі.
3. **WEP vs WPA3:**
   * **WEP:** застарілий, слабкий статичний ключ, зламується за хвилини.
   * **WPA3:** сучасний, використовує захищене узгодження ключів (SAE), стійкий до підбору паролів.
4. **Симетричне vs Асиметричне шифрування:**
   * **Симетричне:** один спільний ключ (швидке, але важко передати ключ).
   * **Асиметричне:** пара ключів — відкритий (шифрує) та закритий (розшифровує).
5. **Рукостискання TLS:** Обмін параметрами → Сервер надсилає сертифікат → Перевірка сертифіката та асиметричне узгодження секрету → Симетричне шифрування трафіку.
6. **Чому не можна вимикати перевірку сертифіката (`verify=False`):** Вимкнення позбавляє захисту від атак MITM (людина посередині). Сертифікат підтверджує справжність сервера.
7. **TLS 1.3 vs TLS 1.2:** TLS 1.2 вимагає 2 раунди (2-RTT), а TLS 1.3 — лише 1 раунд (1-RTT), що значно прискорює з'єднання.
8. **Помилки сертифіката в браузері:**
   * **Прострочений:** `NET::ERR_CERT_DATE_INVALID`
   * **Недовірений видавець:** `NET::ERR_CERT_AUTHORITY_INVALID`
9. **ARP-спуфінг:** Хакер надсилає підроблені ARP-відповіді, видаючи свою MAC-адресу за шлюз, щоб перехопити трафік. *Контрзахід:* Static ARP або Dynamic ARP Inspection (DAI).
10. **VPN vs TLS:** TLS захищає трафік конкретного застосунку/сайту, а VPN шифрує увесь мережевий трафік пристрою.
11. **4-way handshake у WPA2:** Дозволяє перевірити знання пароля та сформувати сеансовий ключ через випадкові числа (nonce) і хеші, не передаючи самий пароль в ефір.
12. **SAE у WPA3:** Сторони доводять знання пароля одночасно та рівноправно без передачі даних для офлайн-перебору (dictionary attack).


## Домашнє завдання

### 1. Порівняльна таблиця протоколів Wi-Fi

| Протокол | Алгоритм шифрування | Тип ключа | Основні вразливості |
| :--- | :--- | :--- | :--- |
| **WEP** | RC4 | Статичний | Зламується за хвилини через слабкий алгоритм |
| **WPA2** | AES (CCMP) | Динамічний | Вразливий до офлайн-підбору пароля через 4-way handshake |
| **WPA3** | AES (GCMP) / SAE | Динамічний | Захищений від офлайн-підбору паролів |

### 2. Дані сертифіката HTTPS (`google.com`)
* **Кому виданий (Subject/CN):** `google.com`
* **Ким виданий (Issuer):** `GTS CA 1C3`
* **Термін дії (Validity):** `15.09.2026 – 08.12.2026`
* **Алгоритм підпису / ключа:** `RSA 2048-bit` (або `ECDSA P-256`)

### 3. Кроки рукостискання TLS
1. **ClientHello:** Клієнт надсилає список шифрів та свій випадковий параметр.
2. **ServerHello:** Сервер обирає шифр та надсилає свій випадковий параметр.
3. **Сертифікат:** Сервер надсилає свій цифровий сертифікат.
4. **Узгодження ключа:** Створення спільного секрету *(Асиметрична криптографія)*.
5. **Finished:** Перехід на шифрування.
6. **Передача даних:** Подальший обмін даними *(Симетрична криптографія)*.
